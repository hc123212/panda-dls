## 0. 项目速览

**一句话**：对 7 自由度冗余机械臂 Franka Panda，用纯 NumPy 手写 MDH（Craig 改进 DH）正向运动学与几何雅可比（与 MuJoCo 官方实现对拍到 $10^{-15}$ 量级），构建以阻尼最小二乘为核心的分辨率速度控制器，在 MuJoCo 物理仿真中以 1 kHz 完成"空间圆位置 + 四元数姿态"双闭环轨迹跟踪，并用零空间投影做冗余优化，最后用四组对照实验把每个设计决策量化。

**最终形态**：`scripts/run_track.py` 起 MuJoCo 动力学仿真，Panda 末端沿空间圆运动、姿态同步摆动，误差 RMS 运动学层 $0.04$ mm、动力学层 $4.2$ mm；`results/` 下有全部分析图表、`demo.gif` 与 `demo.mp4`；`docs/技术方案.md` 是立项时的方案（保留原样作为规划阶段的存档），本文档是完工后的交接复盘。

**核心数字一览**（详细口径见 §10）：

| 指标 | 数值 |
|---|---|
| FK / 雅可比 / 四元数对拍 MuJoCo | $\sim 10^{-15}$ / $3.7\times 10^{-15}$ / $10^{-15}$ |
| 静态 IK 收敛率（随机可达位姿） | $96\%$（48/50） |
| 跟踪误差 RMS（运动学层 / 动力学层） | $0.04$ mm / $4.2$ mm |
| 奇异处关节速度需求（伪逆 / 自适应 DLS） | $889$ rad/s / $1.1$ rad/s |
| 可操作度保持（零空间梯度项） | $3.5\times$ |
| 限位救援（$q_7$ 贴限位起始，零空间开/关） | 裕度 $0$ vs $0.035$ rad，姿态误差 $6.58^\circ$ vs $0.01^\circ$ |

**怎么跑**：见 §15 命令速查。改动任何核心代码后的第一反应应该是 `python scripts/run_verify.py`，它 30 秒内告诉你有没有把对拍到 $10^{-15}$ 的地基打裂。

## 1. 开发历程实录

本章按实际推进顺序复盘。每个阶段写三件事：交付了什么、卡在哪、教训是什么。教训的完整技术分析分散在对应章节，这里先留索引。

**M0 环境与模型（约半小时）**。装 `matplotlib`、`imageio`（后来又补了 `pytest`、`imageio-ffmpeg`），从 mujoco_menagerie 稀疏克隆 Panda 模型。第一个坑在这里就出现了：`git clone` 连不上，报 `Failed to connect to 127.0.0.1 port 7890`——这台机器的 git 全局配置里有一条 URL 级代理 `http.https://github.com.proxy=http://127.0.0.1:7890`，而代理软件当时没开。两次尝试绕过（`-c http.proxy=`）都无效后才意识到是 URL 级配置项，必须用同名 key 覆盖：`git -c http.https://github.com.proxy= clone ...`；同时实测这台机器直连 GitHub 是通的，所以"代理未开"并不必然阻断克隆。教训：遇到代理问题先 `git config --global --list | grep -i proxy` 看配置层次（全局 URL 级、env 变量、命令行 `-c` 的覆盖优先级），再决定绕行方式。模型放进 `demo/models/franka_emika_panda/`（36 MB，含 mesh），克隆用的临时目录 `.menagerie` 删除时曾被 Windows 文件占用锁住，重启资源管理器后才清掉——Windows 下删刚 clone 完的目录遇到 "Device or resource busy" 不用慌，稍后再删即可。

**M1 MDH 建模（半天，全项目最大的坎）**。目标：手写 FK 与 MuJoCo 对拍到 $10^{-9}$。没有抄文献参数表，而是"三步标定法"：从 MuJoCo 读关节轴几何（`run_verify.py` 第 1 节会打印）→ 手推 MDH 表 → 随机位形对拍。推导过程见 §3，结论出乎意料地干净（$\theta$ 偏置全为 0，menagerie 用 body 四元数把关节零位直接做成了 MDH 零位）。但首跑对拍时 hand 旋转误差卡在 $3.5\times 10^{-8}$——其余全是 $10^{-15}$，这个"孤立的、恰好 $10^{-8}$ 量级"的误差最终定位为 XML 四元数只有 7 位小数的舍入差（详见 §3.4）。教训：**对拍阈值定在 $10^{-9}$ 而不是"差不多就行"的 $10^{-6}$，就是为了逼出这类问题**；当一个误差比周围高 7 个数量级时，它一定是某个"常数"不是你以为是的东西。

**M2 几何雅可比（一小时内）**。推导顺畅（§4），一次通过：对拍 `mj_jac` 得 $3.7\times 10^{-15}$，中心差分校验 $2.1\times 10^{-10}$（差分方法本身的量级，符合预期）。唯一要小心的是参考点对齐与 MuJoCo 返回 $3\times 9$ 矩阵（多出两个手指关节）需要切片，见 §4。

**M3 四元数 + DLS + 静态 IK（半天，调试最密集）**。四元数工具一次通过（与 `mju_mat2Quat` 对拍 $10^{-15}$）。静态 IK 收敛率首跑只有 $54\%$，远低于 $95\%$ 的验收线。诊断过程值得完整复述（方法见 §6.3）：写了个循环脚本打印失败案例每次迭代的 $\|e_p\|$、$\|e_o\|$、$\sigma_{\min}$、$\lambda$、$\|\Delta q\|_\infty$ 和贴限位关节数，看到误差在 $1.1$ cm 处冻结、$\|\Delta q\|\to 0$ 而 $\lambda$ 钉在 $0.097$——阻尼把误差"顶"住了。第一层修复是把阻尼激活阈值 $\varepsilon$ 从 $0.10$ 降到 $0.03$ 并引入两阶段求解（阻尼粗收敛 + $\lambda=0$ 纯伪逆抛光），收敛率到 $94\%$；再诊断剩余 3 例，全是关节限位盆地（当前解贴限位、目标解离限位还有 $0.19$ rad 以上），加多起点重启后到 $96\%$。教训：**DLS 当求解器用必须处理不动点偏置，硬裁剪限位会制造"换条路就能走通"的假死盆地**；修复前先打印迭代轨迹，让数据说话，而不是盲调参数。

**M4 轨迹模块（半小时）**。五次多项式时间律 + 空间圆 + 前馈，一次写对。真正的坑在 M5 才爆出来。

**M5 运动学层闭环（1 小时，暴露一个设计级错误）**。首跑结果惨烈：姿态误差峰值 $179.98^\circ$、$q_7$ 限位裕度 $0.00$。诊断：姿态需求是绕世界 $z$ 轴连续转 2 圈（$720^\circ$），而手腕三个滚转关节 $j_1, j_5, j_7$ 行程各 $\pm 2.8973$ rad（$\pm 166^\circ$），**合计约 $500^\circ$，物理上就绕不完 $720^\circ$**——控制器写得再好也救不了不可行的需求。改为 $\pm 75^\circ$ 正弦包络摆动后，误差立刻掉到 RMS $0.037$ mm / 姿态 max $0.004^\circ$。教训见 §8.2：轨迹设计前先做关节行程预算。

**M6 动力学层（1 小时，连续三个工程小坑）**。position 舵机闭环本身一次跑通，但收尾连爆三坑：`mujoco.Renderer` 默认离屏缓冲 $640\times 480$，请求 $1280\times 800$ 直接报错（提示语里那个 `my_width` 就是它让你填的占位符）；GIF 用 `mimsave` 攒 520 帧全分辨率位图在内存里再量化，PIL 直接 `MemoryError`，改流式写入解决；MP4 以 10 Hz 采样却按 24 fps 编码，播放速度凭空快 2.4 倍——采样率与帧率必须一致。三个都是工程细节，坑爸程度不高但每一个都会卡住交付，完整记录在 §11。

**M7 零空间（2 小时，失败的实验设计比失败的代码更费时间）**。算法一次写对，但第一版限位实验选在空间圆上跑——圆轨迹离所有限位都很远，零空间开/关结果一模一样（最小裕度都是 $0.432$ rad），图毫无说服力。重新设计实验场景：可操作度实验改用伸向工作空间边界的直线（$m$ 从 $0.084$ 自然掉到 $0.007$，压力真实存在），限位实验让 $q_7$ 从 $-1.8$ rad（距限位 $1.1$ rad）出发且姿态摆动方向恰好把 $q_7$ 往限位推。第二版尝试 $q_7=-2.0$ 起始，零空间开着仍瞬间贴限（说明救援力度不够），收到 $-1.8$ 后得到干净的分界：关=撞限位+姿态误差 $6.58^\circ$，开=不贴限+ $0.01^\circ$。教训见 §7.3：**对比实验的第一步是先把"压力场景"造出来，否则你测的是"无事发生"**。

**M8 奇异对比实验（1 小时）**。伸向边界的直线轨迹 + 三种 $\lambda$ 策略，一次出图即达预期：伪逆需求 $889$ rad/s、固定阻尼 $0.3$ rad/s（但滞后 $48$ mm）、自适应 $1.1$ rad/s（滞后 $30.7$ mm）。这张图后来成为整个项目的招牌素材。

**M9 文档与媒体（半天）**。README、本讲解文档、GIF/MP4 的减容（$46\to 4.6$ MB）、最终全流程回归验证。

**整体节奏**：M0–M9 实际约 2 个工作日。回看时间分布，数学推导与控制实现只占三分之一，其余全部花在"验证发现不对 → 诊断 → 修复 → 重验"的循环上——这就是为什么 §12 的测试体系值得先于任何上层代码搭建。

### 2.3 panda.xml 解剖：动力学与运动学的事实来源

**执行器是理解动力学层误差的钥匙**。7 个臂关节用 `general` 执行器，`biastype="affine"` 意味着力矩为

$$\tau = k_p\,(q_{\text{des}} - q) - k_v\,\dot{q}$$

其中肩肘关节 $k_p=4500$ / $3500$ N·m/rad、$k_v = k_p/10$；腕三关节 $k_p=2000$ 且力矩限幅 $\pm 12$ N·m。也就是说动力学层就是一个关节空间 PD 位置舵机，我们送 $q_{\text{des}}$，它自己闭合关节环。第 8 个执行器驱动夹爪腱（`ctrlrange` 0–255，255 为张开），演示中固定 `ctrl[7] = 255`。

**自由度是 9 不是 7**：`nq = nv = 9`，多出的 2 个是手指滑移关节。由此有两个必须留意的切片：臂关节占 `qpos[:7]`；`mj_jac` 返回 $3\times 9$ 矩阵，对拍时只取 `[:, :7]`。

**运动链结构**：`link1..link7` 逐级嵌套，每个 body 用 `pos` + `quat` 描述相对父位姿，关节轴统一在各自 body 坐标系下为 $z$ 轴（`axis="0 0 1"`），靠 body 四元数（如 link2 的 `quat="1 -1 0 0"` 即 $\mathrm{Rot}_x(-90^\circ)$）变换出实际方向。这个设计的深意在 §3.3 展开——它让关节零位恰好等于 MDH 零位。

## 3. MDH 运动学建模

### 3.1 变换公式

Craig 改进 DH（MDH）的相邻连杆变换为

$$A_i = \mathrm{Rot}_x(\alpha_{i-1})\,\mathrm{Trans}_x(a_{i-1})\,\mathrm{Rot}_z(\theta_i)\,\mathrm{Trans}_z(d_i),\qquad \theta_i = q_i + \theta_{i,\text{off}}$$

与标准 DH（SDH，$\mathrm{Rot}_z(\theta)\mathrm{Trans}_z(d)\mathrm{Trans}_x(a)\mathrm{Rot}_x(\alpha)$）的区别只是连杆坐标系约定的不同：SDH 把 $\alpha, a$ "挂"在轴 $i$ 的高端，MDH 挂在轴 $i-1$ 的高端。同一机器人可以写出多组合法的 DH 表——符号折叠（轴取 $+y$ 还是 $-y$）、偏置归属（放 $\theta$ 还是放 $d$）都是自由度，这本身就是面试常考的概念题。

`kinematics.py` 的 `mdh_A` 按分块矩阵直接组装，不逐步构造 $4\times 4$ 小矩阵再连乘，一行代码说清楚结构：

$$R = \mathrm{Rot}_x(\alpha)\,\mathrm{Rot}_z(\theta),\qquad p = \mathrm{Rot}_x(\alpha)\begin{bmatrix}a\\0\\0\end{bmatrix} + R\begin{bmatrix}0\\0\\d\end{bmatrix}$$

### 3.2 三步标定法：不抄参数表

**为什么不抄文献表**：能查到的 Panda 参数表几乎都是 SDH 表述，转 MDH 要错位一格且各家符号约定不同；更致命的是文献表的"零位"未必是 MuJoCo 模型的关节零位。抄表的人面对对拍失败时的第一反应永远是"再找一张表"，而正确做法是从模型事实出发。

**三步**：

1. **读**：`mj_forward` 后取每个关节所属 body 的 `xpos`（关节轴锚点，因为铰链的 `jnt_pos` 默认在 body 原点）与 `xmat @ jnt_axis`（世界系轴方向）。$q=0$ 时的实测值是 §3.3 的那张轴表；
2. **推**：按 MDH 定义逐关节解算——$\alpha_{i-1}$ 是绕公垂线方向 $x_{i-1}$ 把 $z_{i-1}$ 转到 $z_i$ 的有向角，$a_{i-1}$ 是公垂线长（可负），$d_i$ 是沿 $z_i$ 滑移到下一条公垂线交点的距离，$\theta_{i,\text{off}}$ 由"MDH 零位必须重合模型零位"反解；
3. **拍**：500 组随机位形对拍 `mj_kinematics`，位置与旋转误差都要 $< 10^{-9}$（实际达到 $10^{-15}$）。

手推时几个容易错的点：关节 4、6 的轴是 $-y$ 而不是 $+y$，符号要么折进 $\alpha$ 的正负要么折进 $\theta$ 偏置；关节 5 到 7 之间 $a$ 出现负值（$-0.0825$）是正常且必要的——MDH 允许 $a<0$，强行全正反而会把误差推到别处；末端工具变换 $\mathrm{Trans}_z(0.107)\cdot\mathrm{Rot}_z(-45^\circ)$（link7→hand）不属于 DH 链，单独作为固定变换 $T_{\text{tool}}$ 处理。

### 3.3 实测标定结果

| 关节 | 轴上锚点 (m) | 轴方向（世界系） |
|---|---|---|
| 1 | $(0,\ 0,\ 0.333)$ | $+z$ |
| 2 | $(0,\ 0,\ 0.333)$ | $+y$ |
| 3 | $(0,\ 0,\ 0.649)$ | $+z$ |
| 4 | $(0.0825,\ 0,\ 0.649)$ | $-y$ |
| 5 | $(0,\ 0,\ 1.033)$ | $+z$ |
| 6 | $(0,\ 0,\ 1.033)$ | $-y$ |
| 7 | $(0.088,\ 0,\ 1.033)$ | $-z$ |

由它推得的 MDH 表（`kinematics.py` 中的 `MDH` 常量）：

| $i$ | $\alpha_{i-1}$ | $a_{i-1}$ (m) | $d_i$ (m) | $\theta_{i,\text{off}}$ |
|---|---|---|---|---|
| 1 | $0$ | $0$ | $0.333$ | $0$ |
| 2 | $-\pi/2$ | $0$ | $0$ | $0$ |
| 3 | $+\pi/2$ | $0$ | $0.316$ | $0$ |
| 4 | $+\pi/2$ | $0.0825$ | $0$ | $0$ |
| 5 | $-\pi/2$ | $-0.0825$ | $0.384$ | $0$ |
| 6 | $+\pi/2$ | $0$ | $0$ | $0$ |
| 7 | $+\pi/2$ | $0.088$ | $0$ | $0$ |

**$\theta$ 偏置全为 0 是一个结论而非前提**：menagerie 通过 body 四元数（link2 的 $\mathrm{Rot}_x(-90^\circ)$ 等）把"关节零位"直接构造成了 MDH 零位，这是该模型库的精心设计。但它不能外推——换成官方 franka_description 或自建 XML，偏置通常非零。所以流程里"反解 $\theta_{i,\text{off}}$ 再对拍"这一步必须保留，结论干净只是运气好的红利。

### 3.4 踩坑：XML 四元数只有 7 位小数

首跑对拍的现象：link7 全部误差 $10^{-15}$，hand 旋转误差却卡在 $3.488\times 10^{-8}$，hand 位置又是 $10^{-15}$。定位思路：误差只出现在"经过 hand 变换的旋转"上 → 检查 $T_{\text{tool}}$ 的旋转 → XML 原文是

```xml
<body name="hand" pos="0 0 0.107" quat="0.9238795 0 0 -0.3826834">
```

$\cos(22.5^\circ) = 0.92387953\ldots$，XML 只写了 7 位。MuJoCo 加载的就是这个舍入值，而我用解析值 $\mathrm{Rot}_z(-45^\circ)$，两者天然差 $10^{-8}$ 量级。修复：`kinematics.TOOL_QUAT` 直接按 XML 原文取值，用四元数转矩阵生成 $R_{\text{tool}}$，误差回到 $2\times 10^{-15}$。**方法论**：对拍出现"孤立的、高出若干量级"的误差时，沿数据流找第一个"我自以为的常数"，逐位和源头比对；这类 bug 不修，会污染所有下游精度指标，还会让你误判更深层的问题。

## 4. 几何雅可比

世界系几何雅可比，参考点取 hand 原点：

$$J_{v,i} = z_i \times (p_{\text{hand}} - O_i),\qquad J_{\omega,i} = z_i$$

其中 $O_i$、$z_i$ 是第 $i$ 关节轴上的锚点与单位方向。实现上零额外计算——`fk_frames` 在逐关节累乘 $A_i$ 时顺手记录每个关节"过 $\mathrm{Rot}_x$、$\mathrm{Trans}_x$ 之后、$\mathrm{Rot}_z$ 之前"的瞬时坐标系：此时 $z$ 轴已经对齐关节 $i+1$（$\mathrm{Rot}_z$ 不动 $z$ 轴、$\mathrm{Trans}_z$ 沿 $z$ 滑移），原点恰是公垂线与轴的交点。

三个对拍细节，都是早期就要定死的口径：

1. **参考点必须一致**：`mj_jac(model, data, jacp, jacr, point, body)` 返回的是指定 `point` 处的平移速度雅可比。对拍时 `point` 传 `data.xpos[hand_id]`，与自研实现的 $p_{\text{hand}}$ 完全同点。换参考点需要刚体速度平移定理 $\dot{p}_{B} = \dot{p}_{A} + \omega \times (p_B - p_A)$ 修正，两边各改一半就永远对不上；
2. **坐标系必须一致**：角速度行是世界系，姿态误差（§5）也必须是世界系轴角。用体坐标系则两边全部换成 $\cdot^T$ 版本。混用是分辨率控制最经典的 bug，症状是"位置收敛、姿态打转"；
3. **切片**：`mj_jac` 返回 $3\times 9$（含手指），对拍取前 7 列。

验收：`mj_jac` 对拍逐元素误差 $3.7\times 10^{-15}$；中心差分（$h=10^{-6}$，姿态部分用 $\log(R(q+h e_i)\,R(q-h e_i)^T)^\vee / 2h$）对拍 $2.1\times 10^{-10}$——这是差分方法的正常量级，两条独立证据链都闭合。

## 5. 姿态数学：四元数、对数映射与误差度量

约定与 MuJoCo 一致：四元数为 $(w, x, y, z)$。

**双覆盖**：$q$ 与 $-q$ 表示同一旋转。所有会"比较/插值"四元数的地方都要处理：`slerp` 在 $\mathrm{dot}(q_0, q_1) < 0$ 时翻转 $q_1$；与 `mju_mat2Quat` 对拍时取 $\|q_{\text{ours}} - q_{\text{mj}}\|$ 与 $\|q_{\text{ours}} + q_{\text{mj}}\|$ 的较小者。`q_from_R` 用 Shepperd 分支法（按旋转矩阵对角元最大者选公式），避免小角度时除以接近零的数。

**控制通道用对数映射**。姿态误差进 6D twist 必须是 3 维轴角向量：

$$e_o = \log\big(R_d\, R^T\big)^\vee = u\,\theta,\qquad \theta \in [0, \pi]$$

理由有三：雅可比角速度行所在的空间就是世界系角速度，误差必须投到同一切空间；对数映射天然取短弧（$\theta\le\pi$），双覆盖问题自动消失；小角度时它就是近似线性的比例误差，闭环增益 $k_o$ 直观。`rot_log` 的三个分支是面试可讲细节：小角度（$\theta<10^{-8}$）直接用反对称分量的一半，避免除以 $\sin\theta$；常规分支除以 $2\sin\theta$；$\theta\approx\pi$ 时反对称部分趋于零，转轴从 $(R+I)/2 = u u^T$ 的对角元开方恢复，并用绝对值最大行的符号整列校正。测试里专门放了 $\mathrm{Rot}_x(\pi)$ 的用例打这个分支。

**评估通道用 chordal 距离**：

$$c = \big\|R_d^T R - I\big\|_F,\qquad \theta_{\text{err}} = 2\arcsin\!\Big(\frac{c}{2\sqrt{2}}\Big)$$

恒等式 $\|R_d^T R - I\|_F = 2\sqrt{2}\,\sin(\theta/2)$ 把 chordal 距离与物理转角一一对应（$c\in[0, 2\sqrt{2}]$）。评估口径选 chordal 是因为它对左右乘旋转双不变、无三角分支问题、适合做 PASS/FAIL 阈值；与 MuJoCo `mju_subQuat` 的物理转角口径一致，可交叉验证。**控制喂向量、评估报标量，两套口径各司其职**。

**slerp** 用于姿态插值（含 dot 翻转与角极小退化处理）。为什么不接受欧拉角插值：同一姿态的欧拉角表示不唯一、插值路径不短、大角度绕远、万向锁——一句话就能讲清，但演示 GIF 里"末端像搅动圆面一样平滑转动"的效果就是 slerp 给的。

## 6. DLS 控制器：推导、自适应阻尼与稳态偏置

### 6.1 从最小二乘到阻尼正则

分辨率速度控制每周期解一个欠定方程 $J\,\Delta q = \dot{x}$（6 个方程、7 个未知数）。最小范数最小二乘解是伪逆 $\Delta q = J^+\dot{x} = J^T(JJ^T)^{-1}\dot{x}$，但当 $JJ^T$ 的最小特征值趋于 0（工作空间边界、腕奇异），解的范数趋于无穷。DLS 加 Tikhonov 正则：

$$\min_{\Delta q}\ \big\|J\,\Delta q - \dot{x}\big\|^2 + \lambda^2\big\|\Delta q\big\|^2 \quad\Longrightarrow\quad \Delta q = J^T\big(JJ^T + \lambda^2 I_6\big)^{-1}\dot{x}$$

SVD 视角下（$J = U\Sigma V^T$）：

$$\Delta q = V\,\mathrm{diag}\!\Big(\frac{\sigma_i}{\sigma_i^2 + \lambda^2}\Big)\,U^T\dot{x}$$

每个奇异方向的增益从无阻尼的 $1/\sigma_i$（$\sigma_i\to 0$ 时爆炸）被压成 $\sigma_i/(\sigma_i^2+\lambda^2)$（峰值封顶 $1/2\lambda$）。**用可控的精度偏差换取数值连续性**——这句话是整个方法的一句话总结。

控制器最终形态（误差增益 + 前馈）：

$$\Delta q = J^T\big(JJ^T + \lambda^2 I_6\big)^{-1}\big(K\,e + \dot{x}_d\big),\qquad K = \mathrm{diag}(k_p I_3,\ k_o I_3)$$

### 6.2 自适应阻尼调度

固定 $\lambda>0$ 意味着永远背着精度偏差；$\lambda=0$ 则奇异处爆炸。工程折中是让 $\lambda$ 随即时状态调度（Nakamura 式）：

$$\lambda^2 = \begin{cases}\lambda_0^2\Big(1 - \big(\sigma_{\min}/\varepsilon\big)^2\Big), & \sigma_{\min} < \varepsilon\\[4pt] 0, & \sigma_{\min} \ge \varepsilon\end{cases}$$

本项目取 $\lambda_0=0.15$、$\varepsilon=0.03$（$J$ 以米计，Panda 灵活工作区 $\sigma_{\min}$ 约 $0.04$–$0.2$，阈值 $0.03$ 意味着只有真接近奇异才介入；主轨迹全程 $\sigma_{\min}\approx 0.21$，阻尼激活时间 $0\%$）。SVD 本来就要算（日志要记 $\sigma_{\min}$ 与条件数），调度是免费的。

### 6.3 稳态偏置：现象、机理与两阶段解法

把同一公式按迭代法用作静态 IK（$q_{k+1} = q_k + \Delta q_k$）时，首跑收敛率只有 $54\%$。诊断脚本打印失败案例的迭代轨迹，典型形态是：误差快速降到 $1.13\times 10^{-2}$ m 后冻结，$\|\Delta q\|_\infty \to 0$，$\sigma_{\min}$ 钉在 $0.024$，$\lambda$ 钉在 $0.097$。

**机理**：阻尼解在 SVD 下第 $i$ 个误差方向的每步收缩率为

$$\text{gain}_i \cdot \sigma_i = \frac{\sigma_i^2}{\sigma_i^2 + \lambda^2}$$

当某方向 $\sigma_i \ll \lambda$ 时收缩率趋近 $(\sigma_i/\lambda)^2 \approx 0$——误差沿近奇异方向被"冻结"。实测该案例其实有两个小奇异值（$\sigma_5\approx 0.024$、$\sigma_6\approx 5\times 10^{-4}$），$\lambda=0.097$ 下冻结方向的收缩率约 $10^{-5}$/步，300 步迭代纹丝不动。这就是 **DLS 的稳态偏置**：$\lambda>0$ 时迭代的不动点在近奇异方向上不是 $e=0$。

**两阶段解法**（`solve_ik`）：阶段 1 用自适应阻尼稳健地接近（远离奇异时 $\lambda=0$ 本就无偏、收缩率为 1）；阶段 2 切 $\lambda=0$ 纯伪逆抛光——此时该方向增益恢复 $\sigma\cdot(1/\sigma)=1$，完整的牛顿步，收敛到公差。预算按 $70\%/30\%$ 分配迭代次数。

修复效果：$54\%\to 94\%$。剩余 3 个失败案例（见下）再用多起点重启解决，最终 $96\%$（48/50，平均 87 次迭代）。

**在线跟踪为什么可以不抛光**：跟踪时误差是持续被轨迹拉动的瞬态量，且前馈项 $\dot{x}_d$ 扛走了速度需求的主要部分，反馈只需修残差——实验 3（§10）里前馈把 RMS 从 $46.2$ mm 压到 $0.04$ mm 就是这句话的数值证据。

### 6.4 限位盆地与多起点重启

两阶段后仍失败的 3 例共同特征：解贴在关节限位上（裕度 $0.000$）而目标位姿对应的关节离限位还有 $0.19$–$0.31$ rad。机理：任务误差方向本身指向限位时，零空间无能为力（它只能在"不动主任务"的子空间里起作用），硬裁剪让迭代停摆——这个盆地里无论迭代多少步都出不去。数值 IK 的标准工程实践就是**换起点重试**（最多 3 次，重启点在限位区间内随机撒），换条路绕开盆地。

### 6.5 实现细节备忘

- **不显式求逆**：`np.linalg.solve(JJt, xd)` 走 LU 分解，比 `inv()` 数值更稳；`dq_task = J.T @ y`；
- **伪逆对照模式防炸**：`lam_mode="none"` 时 `JJt` 加 $10^{-12}$ 正则，避免精确奇异时 `solve` 抛异常（奇异实验需要这个模式"裸奔"）；
- **速度限幅保方向**：缩放因子取全关节最小的 $\min(1, \Delta q_{\max,i}/|\Delta q_i|)$，整体缩放不改变各关节比例；奇异实验里专门 `clamp_dq=False`，否则限幅会把"伪逆需求 889 rad/s"这个关键现象裁掉；
- **零空间投影与主任务用同一个阻尼伪逆**（同一个 $JJ^T+\lambda^2I$），保证两部分的正交分解口径一致。

## 7. 零空间与冗余利用

### 7.1 数学

$7-6=1$ 维零空间。梯度投影法在主任务解上叠加零空间分量：

$$\Delta q = J^+\big(K e + \dot{x}_d\big) + \big(I_7 - J^+ J\big)\,k_n\,z(q),\qquad N(q) = I_7 - J^+ J$$

$N(q)$ 是到 $\mathrm{null}(J)$ 的正交投影，零空间分量在任务空间的一阶效应为零——这就是"次任务不伤主任务"的数学保证（实验图里两条误差曲线几乎重合就是它的可视化）。

### 7.2 两个次任务

`secondary_task` 按配置加权合成：

- **限位中值吸引**：$z_{\text{limit}} = \dfrac{q_{\text{mid}} - q}{q_{\text{half}}}$（逐关节归一化为无量纲 $O(1)$），$k_{\text{limit}}=0.5$；
- **可操作度最大化**：$z_{\text{manip}} = \nabla_q m(q)$，$m(q) = \sqrt{\det(JJ^T)}$（Yoshikawa）。梯度用中心差分（7 维、14 次 FK，每步几十微秒，完全可接受）；解析梯度 $\sum_i \frac{m}{\sigma_i}\frac{\partial \sigma_i}{\partial q}$ 留作扩展。

### 7.3 教训：实验设计比算法难写

第一版限位实验放在空间圆上，跑出来的开/关结果**一模一样**（最小裕度都是 $0.432$ rad）——因为圆轨迹离所有限位都很远，零空间根本没遇到需要它的问题，我测的是"无事发生"。重新设计场景的原则：**先造压力，再看救援**。

- 可操作度实验改用伸向工作空间边界的直线：$m$ 自然从 $0.084$ 掉到 $0.007$，梯度项把它维持在 $0.024$（$3.5\times$），且两条主任务误差曲线几乎重合；
- 限位实验让 $q_7$ 从 $-1.8$ rad 出发（距限位 $1.1$ rad），姿态摆动方向恰好把 $q_7$ 往限位推。中间试过 $q_7=-2.0$，零空间开着仍瞬间贴限——救援力度与需求强度要匹配，参数是设计出来的是通过实验迭代确认的，不是拍出来的。

最终这组实验给出了全项目最干净的一张对比：零空间关 = 撞限位 + 姿态误差 $6.58^\circ$；开 = 全程最小裕度 $0.035$ rad + 姿态误差 $0.01^\circ$。

## 8. 轨迹生成

### 8.1 五次多项式时间律

归一化五次多项式 $s(\tau) = 10\tau^3 - 15\tau^4 + 6\tau^5$（$\tau = t/T \in [0,1]$）满足两端 $s=s'=s''=0$：位置、速度、加速度全连续，比梯形律平滑（jerk 有限）。位置与姿态角**共用**这一条时间律，端点速度自然为零，不需要单独的姿态梯形规划。前馈由解析导数给出（圆轨迹：$\dot{p} = r\dot{\varphi}\,[-\sin\varphi,\ \cos\varphi,\ 0]^T$，$\omega = \dot{\theta}\,\hat{z}$），避免数值微分。

### 8.2 事故复盘：720° 姿态需求不可行

初版主打轨迹让姿态绕世界 $z$ 轴连续转 2 圈（$720^\circ$），"搅拌"效果炫酷。运动学层首跑直接爆炸：姿态误差峰值 $179.98^\circ$、$q_7$ 限位裕度 $0.00$。

诊断后发现这不是 bug 而是不可行需求：手腕三个滚转关节 $j_1, j_5, j_7$ 行程各 $\pm 2.8973$ rad（$\approx\pm 166^\circ$），即使全部用于绕 $z$ 的回转，总行程也只有约 $500^\circ$，物理上完不成 $720^\circ$。**控制器再好也救不了关节空间里不存在的解**。

修正方案：姿态改为 $\pm 75^\circ$ 的正弦包络摆动 $\theta(t) = A\sin(\pi s(t))$（$A = 75^\circ$，主要由 $q_7$ 吸收，行程充裕），位置任务不变。修正后运动学层误差立刻达到 RMS $0.037$ mm / 姿态 max $0.004^\circ$。

**方法论沉淀**：任何"末端绕轴连续旋转 $n\pi$"类需求，落地前先做两个预算——关节行程预算（本例）与关节速度预算（角速度峰值 $\dot\theta_{\max} = A\pi\max s'(t)/T$ 要小于 $q_7$ 限速 $2.61$ rad/s）。预算不过，改需求比改控制器便宜得多。

## 9. 仿真闭环：两层架构

**运动学层**（`mode="kinematic"`）：$q \leftarrow q + \Delta q\,\Delta t$ 直接积分写 `qpos`，无动力学干扰。作用是验证控制律与轨迹本身的正确性——这一层 RMS $0.04$ mm，说明算法误差就是离散化量级。

**动力学层**（`mode="dynamic"`）：$\Delta q$ 积分为 $q_{\text{des}}$，以 1 kHz 下发给 §2.3 的 PD 位置舵机，`mj_step` 积分刚体动力学。RMS $4.2$ mm。**两层之差就是执行/动力学误差**——PD 舵机带宽、重力下垂、跟踪相位滞后的总和。"算法误差与执行误差分解"这个意识是面试里区分"跑过仿真"和"理解系统"的关键，也是未来换真机时判断误差来源的第一张地图。

实现要点：控制器每步用**自研 FK/雅可比**（已对拍 $10^{-15}$），不调 `mj_forward`——快一个量级且口径统一；动力学层把 `d.qpos[:7]` 当"测量值"读（带执行器动态的真实状态），仿真器只负责积分与渲染；夹爪 `ctrl[7]=255` 固定张开。

进阶路线（未做，面试可讲）：`mj_inverseDynamics` 计算重力补偿力矩前馈，预期可把动力学层误差再压一个量级；再往上是计算力矩控制与阻抗控制——那已经是力控的门槛了。

## 10. 实验体系与结果解读

四组对照实验由 `scripts/run_experiments.py` 一键复现，全部为运动学层闭环（隔离执行器因素），仅阶段对比实验含动力学层。逐图解读：

**实验 1：奇异鲁棒性（`singularity.png`）**。轨迹：从初始位姿沿 $+x$ 伸向工作空间边界 $0.32$ m，恒姿态，8 s。三组配置：$\lambda=0$（伪逆）、固定 $\lambda=0.15$、自适应（$\lambda_0=0.15$，$\varepsilon=0.03$），全部关闭速度限幅以暴露"原始需求"。结果：伪逆在 $t\approx 6$ s（$\sigma_{\min}\to 0$）需求飙至 $889$ rad/s，位置误差积分后发散到 $440$ mm；固定阻尼全程平滑（峰值 $0.3$ rad/s）但阻尼偏置让它跟不上目标（末端 $48$ mm，$\sigma_{\min}$ 只探到 $0.065$）；自适应阻尼峰值 $1.1$ rad/s、探到 $\sigma_{\min}=0.013$、末端误差 $30.7$ mm。**看图方法**：上图对数轴看"炸不炸"，下图看"跟多深"。结论一句话：伪逆快但爆炸、固定阻尼安全但迟钝、自适应是工程最优折中——三种策略各有代价，没有免费午餐。

**实验 2a：零空间可操作度（`nullspace_manip.png`）**。同一边界直线，开/关 $k_{\text{manip}}=5$ 的梯度项。关：$m$ 末端 $0.0069$；开：$0.0242$（$3.5\times$），且主任务误差曲线几乎重合（末端 $30.2$ vs $33.1$ mm，均为阻尼偏置贡献）。

**实验 2b：零空间限位救援（`nullspace_limit.png`）**。$q_7=-1.8$ 起始 + 空间圆姿态摆动。关：$q_7$ 贴限（裕度 $0.000$，图上可见被限位"削平"的线段），姿态误差 $6.58^\circ$；开：裕度 $0.035$ rad，姿态误差 $0.01^\circ$。看图重点：$q_5$ 曲线在"开"时主动下探 $-0.3$ rad——零空间动用冗余把 $q_7$ 的活儿分走了一部分。

**实验 3：前馈开/关（`feedforward.png`）**。无前馈 RMS $46.2$ mm（max $69.1$ mm），有前馈 $0.04$ mm。滞后型误差 $\propto$ 速度/增益，曲线形状与五次律速度包络同步——**误差曲线的形状本身就是诊断证据**，这一条在面试讲"你怎么调控制器"时非常好用。

**实验 4：运动学层 vs 动力学层（`stage_ab.png`）**。$0.039$ vs $4.24$ mm，姿态 $0.01^\circ$ vs $1.28^\circ$。差值即执行误差（PD 舵机带宽 + 重力 + 相位滞后）。

## 13. 局限与扩展路线

诚实清单（面试主动讲是加分项）：

| 局限 | 扩展路线 | 难度 |
|---|---|---|
| 关节限位 = 硬裁剪 + 零空间吸引，贴限位时主任务仍可能降级 | 加权最小二乘（WLS）：$\Delta q = W^{-1}J^T(JW^{-1}J^T+\lambda^2 I)^{-1}\dot{x}$，限位附近权重增大，把软约束织进主任务 | 中 |
| 可操作度梯度是数值差分 | 解析梯度或 SVD 灵敏度 | 低 |
| 速度级控制，无动力学模型参与 | `mj_inverseDynamics` 重力补偿前馈 → 计算力矩 → 阻抗控制 | 中→高 |
| 单一零空间次任务 | 严格任务优先级（Siciliano）或加权 QP（参考 pink / mink 的做法） | 中 |
| Python 原型 | 核心数学零依赖 NumPy，接口已隔离（`dls_step(q, xd, J, cfg)`），Eigen/C++ 直译；输出 $\Delta q$ 天然对接 ros2_control 的 velocity/position controller | 中 |
| 姿态连续大角度旋转不可行 | 允许关节回绕（穿越重构位形）或姿态任务降权 | 高 |

## 14. 面试问答弹药库

1. **为什么用 DLS 而不是解析 IK 或牛顿法？** Panda 7 自由度无闭式解；纯伪逆在奇异处 $1/\sigma\to\infty$。DLS 是 Tikhonov 正则，SVD 视角下把每个奇异方向的增益从 $1/\sigma$ 压到 $\sigma/(\sigma^2+\lambda^2)$，且 $\lambda$ 可随 $\sigma_{\min}$ 在线调度。我的实验：伪逆需求 $889$ rad/s，自适应 DLS 压到 $1.1$ rad/s。
2. **DLS 的代价是什么？** 稳态偏置：近奇异方向每步收缩率只有 $(\sigma/\lambda)^2$，误差会被"冻结"。离线 IK 用两阶段（阻尼粗收敛 + $\lambda=0$ 抛光）解决；在线跟踪用前馈扛速度需求，反馈只修残差。
3. **姿态误差为什么用对数映射而不用欧拉角差？** 控制误差必须落在雅可比角速度所在的切空间；欧拉角差不可微、表示不唯一、有万向锁。评估用 chordal（SO(3) 双不变度量）换算物理转角 $\theta = 2\arcsin(c/2\sqrt{2})$，两套口径各司其职。
4. **四元数双覆盖怎么处理？** slerp 前 dot $<0$ 翻转；对数映射天然取短弧（$\theta\le\pi$）无此问题。
5. **冗余自由度怎么用？** 梯度投影法：$N(q)=I-J^+J$ 把次任务投到零空间，主任务一阶不受影响（有实验图佐证）；推广是任务优先级与加权 QP。
6. **动力学层 4.2 mm 的误差是什么水平、怎么再压？** 运动学层证明算法误差只有 $0.04$ mm，剩下是 PD 舵机带宽与重力下垂；加重力补偿前馈可再压一个量级，代价是依赖动力学模型。
7. **怎么上真机？** 控制器输出就是关节速度/位置指令，对接 ros2_control；控制频率 1 kHz 对齐 Panda 官方口径；力矩层需要动力学辨识。
8. **跟踪误差曲线为什么和速度包络同步？** 滞后型误差 $\propto$ 速度/增益，前馈消的正是这一项——曲线形状本身就是诊断证据（配合实验 3 的 46 mm → 0.04 mm）。
9. **如果 $\sigma_{\min}$ 测量有噪声怎么办？** 先低通滤波再调度 $\lambda$，避免阻尼抖振；也可以对 $\lambda$ 本身加变化率限制。
10. **你的参数（$\lambda_0, \varepsilon, k_{\text{limit}}, k_p, k_o$）是怎么定的？** 每个都能讲出"定错的版本 + 现象 + 修正依据"：$\varepsilon=0.10$ 时 IK 只有 $54\%$（§6.3），$k_{\text{limit}}$ 在 $q_7=-2.0$ 起始场景下救援不足（§7.3）——参数是实验迭代出来的，不是拍的。

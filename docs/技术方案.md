# 基于 MuJoCo 与阻尼最小二乘法（DLS）的 Panda 机械臂笛卡尔空间轨迹跟踪与姿态控制

> 用途：机械臂运动控制实习生岗位面试演示 demo（对标 JD：IK/FK/四元数、仿真二次开发、多任务控制、算法工程化、真机移植）

## 1. 项目定位与一句话描述

**一句话**：对 7 自由度冗余机械臂 Franka Panda，用 NumPy 手写 MDH 运动学（FK + 几何雅可比），以阻尼最小二乘（DLS）为核心构建分辨率速度控制器，在 MuJoCo 物理仿真中完成笛卡尔空间直线/圆弧轨迹的位置与姿态（四元数）双闭环跟踪；利用零空间投影实现关节限位规避与可操作度优化，并通过奇异值分析实验对比伪逆 / 固定阻尼 / 自适应阻尼三种方案的鲁棒性。

### 与 JD 的对应关系（面试时可以直接讲的映射）

| JD 要求 | demo 中的体现 |
|---|---|
| IK、FK、四元数 | 手写 MDH-FK、几何雅可比、四元数姿态误差与 slerp 轨迹插值，并与 MuJoCo 官方实现数值对拍 |
| 仿真二次开发 | MuJoCo (3.11) 加载 Panda 模型，自建控制回路驱动物理仿真（执行器层） |
| 机器人多任务控制 | 零空间梯度投影：主任务（末端 6D 跟踪）+ 次任务（关节限位中值吸引 / 可操作度最大化），即任务优先级框架的雏形 |
| 算法工程化 | 模块化包结构、对拍单元测试、指标体系（RMSE/max 误差、奇异值、限位裕度）、自动化出图与 GIF |
| 真机移植（叙事） | 控制器输出为关节速度指令 dq，天然对接 ros2_control 的 velocity/position 接口；核心数学无第三方依赖，可直接 Eigen/C++ 移植（讲路线，不必实现） |

## 3. 数学核心设计

> 按你的习惯：以下公式是"施工图"，代码由你自己实现；卡住时我再给参考实现。
> 每个模块都配"验收标准"，写完立刻对拍，不让误差滚到下一层。

### 3.1 MDH（Craig 改进 DH）正向运动学

Craig 约定下相邻连杆变换：

$$^{i-1}T_i = \mathrm{Rot}_x(\alpha_{i-1})\cdot \mathrm{Trans}_x(a_{i-1})\cdot \mathrm{Rot}_z(\theta_i)\cdot \mathrm{Trans}_z(d_i)$$

末端位姿 $T_{flange} = T_{base}\, A_1 A_2 \cdots A_7\, T_{tool}$，其中 $T_{tool}$ 为法兰到跟踪点（finger/site8）的固定变换。

**Panda 连杆常数（文献锚点，SDH 表述）**：

| 关节 $i$ | $a_i$ (m) | $\alpha_i$ | $d_i$ (m) |
|---|---|---|---|
| 1 | 0 | 0 | 0.333 |
| 2 | 0 | −π/2 | 0 |
| 3 | 0 | π/2 | 0.316 |
| 4 | 0.0825 | π/2 | 0 |
| 5 | −0.0825 | −π/2 | 0.384 |
| 6 | 0 | π/2 | 0 |
| 7 | 0.088 | π/2 | 0 |
| 法兰 | 0 | −π/2? | 0.107 (L8) |

**关键坑（本项目第一个面试讲点）**：
1. 文献表是标准 DH（SDH）或其变体，转 MDH（Craig）时 α/a 要**错位一格**（变成 $\alpha_{i-1}, a_{i-1}$），符号约定各家不同；
2. **MuJoCo 的关节零位 ≠ DH 零位**——menagerie 模型里每个 joint 带 `ref`/`springref` 偏置，直接用 $\theta_i = q_i$ 会整体对不上，必须推导每关节的常值偏置 $\theta_{i,off}$；
3. 因此本项目采用"**三步标定法**"，不裸抄表：

   - **Step 1 读**：`mj_forward` 后读出 7 个关节 body 的 `xpos`（原点）与关节轴方向 `xaxis`（对铰链即 z₇ 系的 z 轴）；
   - **Step 2 推**：由这些几何量手工推 MDH 表（各 $a_{i-1}, \alpha_{i-1}, d_i, \theta_{i,off}$）——手推过程本身就是面试时"我真懂 DH"的证据；
   - **Step 3 对拍**：随机 200 组 $q$，比较 $T_{mdh}(q)$ 与 MuJoCo site 位姿，要求位置误差 < 1e-9 m、旋转矩阵逐元素差 < 1e-9。不达标不许进下一步。

### 3.2 几何雅可比

对 MDH 链逐关节累乘得各关节原点 $p_i$ 与轴 $z_i$，则

$$J_{v,i} = z_{i-1} \times (p_{ee} - p_{i-1}), \qquad J_{\omega,i} = z_{i-1}$$

堆叠成 $J \in \mathbb{R}^{6\times7}$（角速度部分映射到世界系，与 MuJoCo `mj_jac` 的输出约定一致，方便对拍）。

**验收**：与 `mj_jac(m, d, site_id)` 的 3×N 平移块 + 3×N 旋转块对拍 < 1e-8；另加有限差分校验（中心差分 FK）< 1e-6。

### 3.3 六维任务误差：位置 + 姿态

- 位置误差：$e_p = p_d - p$。
- 姿态误差（控制用，进 6D twist 的必须是 3 维轴角向量）：
  $q_e = q_d \otimes q^{-1}$（单位四元数，$w<0$ 时整体取反消除双覆盖），
  $e_o = u\,\theta$，其中 $q_e = [\cos\frac{\theta}{2},\ u\sin\frac{\theta}{2}]$，$\theta\in(-\pi,\pi]$。
- **姿态误差度量（评估用）**：PASS/FAIL 判据用旋转矩阵 Frobenius chordal 距离 $c = \|R_d^T R - I\|_F$；对外报告用换算后的物理转角 $\theta_{err} = 2\arcsin\!\big(c / (2\sqrt{2})\big)$（rad），与 `mju_subQuat` 口径一致。控制向量 $e_o$ 与度量 $\theta_{err}$ 小角度下等价，工程上分别服务于"喂给控制器"与"说人话"两个目的。

### 3.4 DLS 阻尼最小二乘（项目核心）

在线分辨率速度控制（每个控制周期一步，无需迭代收敛）：

$$\Delta q = J^T\big(JJ^T + \lambda^2 I_6\big)^{-1}\big(K\,e + \dot{x}_d\big)$$

- $e = [e_p;\ e_o]$，$K = \mathrm{diag}(K_p I_3, K_o I_3)$ 误差增益（位置 ~ 1/s，姿态 ~ 1/s，先取 1 起步再调）；
- $\dot{x}_d$ 为轨迹前馈（可先置零验证纯反馈收敛，再加前馈看稳态误差改善——对比数据留作讲点）；
- $\lambda$：阻尼正则项。**自适应调度**（Nakamura 式）：

$$\lambda^2 = \begin{cases} \lambda_0^2\left(1 - (\sigma_{min}/\varepsilon)^2\right), & \sigma_{min} < \varepsilon \\ 0, & \sigma_{min} \ge \varepsilon \end{cases}$$

  其中 $\sigma_{min}$ 为 $J$ 的最小奇异值（SVD 顺带免费拿到条件数与可操作度）。远离奇异时 λ→0 退化为伪逆（不牺牲精度），接近奇异时平滑加阻尼抑制 $\|dq\|$ 爆炸。

**零空间投影（冗余利用，对应 JD"多任务控制"）**：

$$\Delta q = \underbrace{J^T(JJ^T+\lambda^2I)^{-1}v}_{主任务} + \underbrace{\big(I_7 - J^T(JJ^T+\lambda^2I)^{-1}J\big)\,k_n\,z(q)}_{零空间次任务}$$

次任务目标 $z(q)$ 实现两个（可切换/加权）：
1. **关节限位中值吸引**：$z = \frac{q_{mid}-q}{n}$（或对越限趋势关节加权），保证长时间轨迹不撞限位；
2. **可操作度最大化**：$z = \nabla_q m(q)$，$m = \sqrt{\det(JJ^T)}$，梯度用中心差分数值实现（7 维足够快；有余力再推解析式）。

**安全层**：关节速度逐关节限幅；关节位置硬 clamp 到 `[joint_range + margin]`；姿态误差超过 π 截断（走短弧）。

### 3.5 静态 IK 收敛测试（控制器的"单元测试"形态）

同一公式按迭代法使用：$q_{k+1} = q_k + \Delta q$，迭代至 $\|e\| < 10^{-5}$ 或 200 次。用于：随机可达位姿收敛率统计（目标 > 95%）、迭代次数分布、不同 λ 下的收敛域对比。这一步把"控制器 bug"和"轨迹/仿真 bug"隔离，出问题先查它。

## 4. 轨迹设计（笛卡尔空间）

统一接口：`traj.sample(t) -> (p_d, R_d, v_d, ω_d)`。

| 场景 | 位置 | 姿态 | 考察点 |
|---|---|---|---|
| T1 直线抓取线 | 两点间五次多项式 $s(\tau)=10\tau^3-15\tau^4+6\tau^5$ | 恒定（初始姿态） | 基础跟踪、零漂检查 |
| T2 空间圆 + 姿态旋转 | $p = c + r[\cos\varphi, \sin\varphi, 0]$，$\varphi$ 匀速转 2 圈 | 绕圆面法向 slerp 连续旋转 2π | 位置+姿态**同时**连续跟踪（主打场景，GIF 就用它） |
| T3(选) 8 字 / 工作空间边界擦边 | Lemniscate | 恒定 | 故意进入低可操作度区，喂给奇异对比实验 |

姿态插值一律用你手写的 slerp（反对用欧拉角插值的理由要能讲：非唯一、万向锁、插值路径不短）。时间律输出配套 $\dot{s}(\tau)$，链式法则得前馈 $\dot{x}_d$。

## 5. 仿真闭环（两阶段）

- **阶段 A（运动学层，先跑通算法）**：`q ← q + dt·Δq` 直接写 `d.qpos[:7]`，`mj_forward`，viewer 里看运动。没有动力学干扰，误差应收敛到数值精度级，用于验证控制律与轨迹本身正确。
- **阶段 B（动力学层，体现"物理仿真二次开发"）**：`q_des` 发给 panda 的 position actuator（menagerie 自带 kp/kv），每步 `mj_step`。跟踪误差会因执行器带宽/重力下垂变大——**这本身是讲点**：报告 A/B 两阶段误差对比，说明"算法误差 vs 执行/动力学误差"的分解意识；进阶（选做）用 `mj_inverseDynamics` 做重力补偿力矩前馈再对比。
- 控制周期 = 仿真步长 = 1–2 ms（Panda 真机控制频率 1 kHz，口径一致，面试可以带一句）。

## 8. 风险与预案

| 风险 | 预案 |
|---|---|
| 文献 MDH 表与 MuJoCo 对不上（零位偏置、α 符号约定） | 就是 3.1 的"三步标定法"，以对拍为唯一标准；手推过程留档作面试材料 |
| 轨迹靠近奇异时 dq 尖峰 | 自适应 λ + 关节速度限幅 + T3 专用（不进主演示轨迹） |
| position actuator 震荡/稳态差 | timestep 1–2 ms；kp/kv 从 menagerie 默认微调；兜底换 motor 执行器 + `mj_inverseDynamics` 重力补偿 |
| 四元数双覆盖导致姿态误差跳变 | $w<0$ 取反；误差角超 π 截断走短弧 |
| 冗余解漂移/撞限位 | 零空间中值吸引 + 位置硬 clamp + 起点选位形空间中部姿态 |
| menagerie 拉取失败 | gitee 镜像 / 代理 / zip 子目录 |

## 9. 面试问答弹药库（demo 讲完后的深水区）

- **为什么用 DLS 而不是解析 IK / 牛顿迭代？** Panda 7-DOF 无闭式解；纯伪逆（牛顿）在奇异附近条件数→∞，解范数爆炸；DLS 是 Tikhonov 正则化，把 $JJ^T+\lambda^2I$ 谱半径抬离 0，用可控精度偏差换数值连续性，且 λ 可随 σ_min 在线调度——demo 里有三条曲线直接证明。
- **控制误差为什么用轴角，评估用 chordal？** 雅可比映射角速度，控制误差必须落在切空间（SO(3) 的 log 映射，3 维向量）；chordal 是 SO(3) 上双射不变的自然度量，便于设 PASS/FAIL 阈值，arcsin 换算回物理角作报告口径。两套口径各司其职。
- **冗余自由度怎么用？** 梯度投影法 = 主任务零空间里的次任务优化；推广方向是严格任务优先级（Siciliano multi-priority）与加权 QP 全身控制器，本 demo 是它们的最小可运行形态。
- **怎么上真机？** 控制器输出就是关节速度/位置指令，对接 ros2_control 的 velocity/position controller 即可；核心数学零依赖 NumPy，接口层隔离好后可直接 Eigen/C++ 移植；力矩层还需动力学模型与重力补偿（demo 阶段 B 已有雏形）。
- **工程上为什么不用现成库（MoveIt/pink）？** 面试 demo 的目的是证明"懂原理 + 能工程化"，核心手写 + 与官方实现对拍正是证据；并明确说明生产中会用成熟库，二者不矛盾。
